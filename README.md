# 🌊 OKEAN Лодка — Управление с браузера по Wi-Fi

Простой проект удалённого управления устройством через веб-интерфейс.  
Устройство — Arduino Nano + модуль ESP-01. Управление — через обычный браузер.

## 📁 Структура проекта

## 🧩 Что делает каждый компонент

### 1. `browser/`
- Простая HTML-страница
- Кнопки для отправки команд
- JavaScript для взаимодействия (пока эмуляция, потом — реальные HTTP-запросы)

### 2. `ESP-01/`
- Работает как Wi-Fi точка доступа (`OKEAN_Lodka`)
- Запускает веб-сервер на порту 80
- Принимает команды от браузера и передаёт их на Arduino через Serial

### 3. `nano_and/`
- Принимает команды от ESP-01 по UART (Serial)
- Управляет физическими устройствами (светодиоды, моторы и т.д.)

## 🚀 Цель проекта
Научиться управлять Arduino через обычный браузер, без мобильных приложений и сложных сред.

## 🔜 Далее
1. Довести веб-интерфейс до ума
2. Настроить связь браузер ↔ ESP-01
3. Передать команды → Arduino Nano
4. Включить реальное устройство (светодиод, реле и т.п.)
